§3 / DEPLOYMENT

Local inference where the network stops.

Deployment patterns, not customer case studies. Models remain advisory and stay out of real-time closed-loop control.

Oil and gas

Rotating-equipment anomaly explanation and operator copilots grounded in the OEM manuals and P&IDs already on site.

Power generation

Historian questions in plain language, alarm-flood triage, and work-order drafting for turbines and substation assets.

Manufacturing

Prompt-defined inspection over the existing classifier, and shift notes, maintenance logs, and fault codes read together.

Aerospace and defense

Document intelligence and assistant workloads on disconnected networks, where deployment is the security model.

Signals. OPC UA and Modbus for tags; MQTT Sparkplug B over a unified namespace for transport. The deployment initiates outbound and exposes no inbound listener.

Models. ISA-95 for the asset hierarchy and NAMUR NE 107 for device-health status, so a verdict lands in the vocabulary operators already use.

Placement. IEC 62443 zones and the Purdue levels decide where the box sits. Protection, interlocks, and safety-instrumented systems stay deterministic; the model reasons beside classical analytics, never in place of it.

Device evidence contract. A device claim names the exact board, runtime, format, quantization, context, peak memory, and measured speed.

Raspberry Pi and NPU. Pi results name model and RAM. NPU results report full delegation, partial delegation, and CPU fallback, not merely a successful load.

ESP32. Roger Edge covers wake, VAD, sensing, and fixed commands. ESP32 does not run Wave Micro; ESP32-P4 claims name the companion radio.

§5 / DEVELOPERS

From artifact to local endpoint.

Released model cards carry exact commands. The flow stays the same across the family.

01

Download

Pull a released artifact and its model card from Hugging Face.

huggingface-cli download rogerai-fyi/DeepSeek-V4-Flash-MTP-GGUF
02

Run locally

Serve GGUF with llama.cpp as an OpenAI-compatible endpoint.

llama-server -m model.gguf --port 8080
03

Broadcast

Optional. Put that endpoint on air so others can tune in.

roger share
