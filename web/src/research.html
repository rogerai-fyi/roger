§2 / PROOF

Claims follow measurements.

Compact pages do not mean hidden evidence.

Reproducible. Published measurements name the hardware, artifact, runtime, settings, and raw results.

Honest lineage. We distinguish training from adaptation, optimization, and verification. Upstream work keeps its original name and license.

Durable. Negative results remain available. Qualifying artifacts use standard formats and runtimes.

Local first. You may download and run qualifying artifacts locally. Publishing through the RogerAI network is optional.

§3 / DEVELOPERS

From artifact to local endpoint.

Released model cards will carry exact commands. The flow stays the same across the family.

01

Download

Pull a released artifact and its model card from Hugging Face.

huggingface-cli download rogerai-fyi/<model>
02

Run locally

Serve GGUF with llama.cpp as an OpenAI-compatible endpoint.

llama-server -m model.gguf --port 8080
03

Reproduce

Match the artifact version, hardware, runtime, and settings from the published evaluation record.

git clone https://github.com/rogerai-fyi/roger
