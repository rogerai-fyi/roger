§2 / RUN

Free on the band, one command away.

Wave Pico is on air as a free band. The band serves the release measured on this page. Install the CLI, then tune in: roger use opens a local OpenAI-compatible endpoint on your own machine, and anything that speaks that API can call it.

§5 / ADAPTER

One adapter, routed per request.

The fire adapter is a {{card:pico.adapter-size}} LoRA adapter for this base. The server loads it beside the model and switches it on only for the requests that ask for it. It is never merged into the base, so the industrial reading stays exactly as measured above.
