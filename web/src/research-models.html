The microcontroller line

Task models, not language models · not a Wave tier · experimental

PROTOTYPE

Roger Edge

ESP32 class boards · intent and anomaly classifiers

no artifact exists
ROLE

Two halves of one line, both down where the sensor already is. A small model that classifies against a fixed set of labels, and the layer around it: wake, voice-activity detection, sampling, fixed commands, and the hop up to a Wave model for anything it cannot name. Roger Edge detects; Wave reasons.

Prototype, actively testing Where it sits in a plant

A classifier in the sensor’s own flash. Roger Edge is a task model: a small classifier with a fixed set of labels, distilled from Wave Pico and quantized to int8, sized to sit in a microcontroller’s flash at kilobytes to a few megabytes. It wakes, watches the signal, names what it recognises, and hands anything it cannot name up to a Wave model. Roger Edge detects; Wave reasons. No Wave tier runs on an ESP32 or an Arduino - the board is the sensor, and a Raspberry Pi is the smallest model host.

The decision happens where the measurement does. A node that can name what it is seeing does not have to send everything it sees. That saves the round trip, the bandwidth and the wait on a link that may not be there, and it fits the power budget of a board running off a panel and a battery. A Wave model runs on whatever machine hosts it, with or without a board like this near the sensor, so this is something a deployment adds where it earns its place.

One line, bench to cabinet. The same job turns up at both ends: an ESP32 and a Pi on a bench at home, and a plant sensor wired to a model in a cabinet. We intend one line for both - the same classifier, and the same contract for what the node sends and what comes back - so what you learn on the bench is what runs in the plant. Which boards ship first is still open.

Write once, build for the board in front of you. Getting a model onto a board is well served already: Arduino for bring-up and library reuse, ESP-IDF for shipping and OTA, Zephyr when one RTOS has to cover several vendors, PlatformIO to build across them, TensorFlow Lite for Microcontrollers and Edge Impulse to compile a network down to something that fits. What none of them standardises is the hop to a language model - what a node sends when it cannot decide, in what format, and what shape the answer comes back in. That hop is what we want to make ordinary: one API for sample, window, features, classify, escalate, packaged the way each ecosystem already expects it, so the same node code moves between boards instead of being rewritten for each one.

Prototype phase. Roger Edge is in prototype. We will publish the pieces as the work advances and each one is ready to be used in public.
