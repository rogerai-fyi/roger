        §4 / THE TUNE
        
Two sides of the same network.

      


      

        

          
go on air

          
Share a model

          
Point RogerAI at your local backend (vLLM, llama.cpp, Ollama, LM Studio, Osaurus). Set a call-sign,
            a rate, and your hours. Flip the switch. You are on air.

          roger share qwen3.8-27b --rate 0.30
        


        

          
        


        

          
tune in

          
Use a model

          
Pick a band, set your margins (max price, min speed). RogerAI locks the strongest
            station and hands you a local OpenAI endpoint + key. When one fades, it re-tunes.

          roger use qwen3.8-27b --max-price 0.30 --min-tps 40
        

      

    

  


  
  
  

    

      

        
        

          §5 / SPECIFICATIONS
          the whole instrument, one plate
        

        

          
Protocol
OpenAI-compatible drop-in

          
Transport
Outbound long-poll no inbound ports

          
Endpoint
127.0.0.1 local, key-scoped

          
Pricing

Settlement
Wallet balance debited live

          
Lineage

Split

Interfaces

Reach

Platforms

Backends
vLLM · llama.cpp · Ollama · LM Studio · Osaurus · LiteLLM · any OpenAI-compatible

      §8 / GO
      
Start with one command.

      
You are installing roger: one binary, a local
        harness for local models. It finds the models already on your machine, puts
        them on air if you want, and tunes you into everyone else’s.

      
      

        On Windows (PowerShell): irm https://rogerai.fm/install.ps1 | iex
      


      

        
Then pick your window. Both drive the same station, the
          same wallet and the same settings - a limit set in one is the limit the
          other enforces.

        

          

            
The dial

            roger
            
The terminal radio: browse the band, tune a station, chat, run the agent,
              put your own models on air.

          

          

            
The console

            roger webui
            
The same radio in a browser tab, with room for tables - sort the band,
              compare stations, and edit prices and caps on a full-width surface.
