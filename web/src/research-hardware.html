The board you already have,
and what it is meant to carry.

The Wave family is sized to hardware, not to benchmarks: a tier exists because a class of machine exists to run it. This is that mapping, from a sensor microcontroller to a desktop datacenter - with each tier’s real stage printed beside it, because most of them are not built yet.

§1 / THE SPECTRUM

One band, five stops, five orders of magnitude.

Left to right is roughly a thousandfold in parameters and a thousandfold in watts. Each stop is a class of machine first and a model second: the tier was specified to fit the box, which is why the boxes are named here at all.

§2 / THE BOARDS

Seven machines, and the tier each one is a target for.

Every card names the tier the board is specified against and that tier’s stage, copied from the model catalogue and checked against it by a test. Read the stage before the tier: most of these are not built yet, and a card that says otherwise is a bug.

ESP32

240 MHz · 520 KB SRAM · no MMU

The sensor itself. Wi-Fi and Bluetooth on the die, a few hundred kilobytes to work in, and a power budget measured in tenths of a watt. This is the class Roger Edge is specified against: a fixed-label classifier and the layer around it, down where the signal is.

Target tier
Roger Edge
Stage
Prototype, actively testing
A station?
No - too small to serve an API

Arduino Uno

16 MHz · 2 KB SRAM · 32 KB flash

Below even the edge tier for a model, and included honestly for that reason: an Uno is the sensor and actuator side of a fleet, not a place a classifier lives. It matters here because it is what the gateway above it talks to.

Target tier
Roger Edge (host side only)
Stage
Prototype, actively testing
A station?
No - sensor and actuator side

Raspberry Pi Pico

RP2040 · 133 MHz · 264 KB SRAM

A microcontroller wearing the Raspberry Pi name, which confuses the ladder more than any other board: it belongs at the Roger Edge stop, not with the Pi 5. Two cores, no operating system, and the same fixed-label job.

Target tier
Roger Edge
Stage
Prototype, actively testing
A station?
No - no OS, no server

Raspberry Pi 5

4–16 GB · no GPU · ~5 W

The first stop with a real operating system, and the machine Wave Pico is specified against by name: a few hundred million parameters, no accelerator, and a target near 50 ms. The smallest box on this page that can hold a conversation rather than a label.

Target tier
Wave Pico
Stage
Certifying the waypoint · 300M retrain next
A station?
Yes - small models today

NVIDIA Jetson

8–64 GB unified · CUDA · 15–60 W

The fleet gateway: the first box with real accelerated inference and a thermal envelope that still fits a cabinet. Wave Nano is specified here - the tier that rolls up many children, resolves their conflicts and routes by discovery.

Target tier
Wave Nano
Stage
Scratch build queued behind Pico
A station?
Yes - a good one

Mac Studio

32–512 GB unified · ~90 W under load

The site brain, and the best power-per-token box on this page: unified memory large enough for a 7–8B model with room to spare, at a draw a desk can ignore. Wave Micro is specified against this class of on-site server.

Target tier
Wave Micro
Stage
Scratch pipeline standing up
A station?
Yes - see the arithmetic

NVIDIA DGX Spark

128 GB coherent · ~240 W · desk-side

A plant datacenter that fits under a desk. Enough coherent memory to hold a 27–35B model without splitting it, which is the whole reason the Wave Giga tier is drawn where it is - full-plant reasoning on one box, inside the fence.

Target tier
Wave Giga
Stage
Base selection
A station?
Yes - the largest here
§3 / TODAY

What you can actually fetch and run this afternoon.

Everything above is a target. Two things on this page are not.

ONE ARTIFACT

DeepSeek-V4-Flash MTP, in GGUF

284B total, 13B active, multi-token prediction, quantised and published by us. It is the only set of weights on this site you can download right now, and it wants the largest machine here or bigger. The build story, including what did not work, is in the broadcast.

ONE COMMAND

Any of these boxes can be a station now

None of that waits on a Wave checkpoint. If a machine on this page can serve an OpenAI-compatible endpoint - the Pi 5 and everything to its right can - roger share finds that server and puts it on the band. Outbound only, so there is nothing to open on a plant network.

STATUS

No Wave checkpoint has been released, and no Roger Edge artifact exists. The tiers on this page are specifications with hardware attached, and each card carries the stage it is genuinely at. When that changes, the catalogue changes first and this page follows it - a test fails if it does not.
