The board you already have,
and what it is meant to carry.

The Wave family is sized to hardware, not to benchmarks: a tier exists because a class of machine exists to run it. This is that mapping, from a sensor microcontroller to a desktop datacenter - with each tier’s real stage printed beside it, because most of them are not built yet.

§1 / THE SPECTRUM

One band, five stops, five orders of magnitude.

Left to right is roughly a thousandfold in parameters and a thousandfold in watts. Each stop is a class of machine first and a model second: the tier was specified to fit the box, which is why the boxes are named here at all.

§2 / THE BOARDS

Ten machines, and the tier each one is a target for.

Every card names the tier the board is specified against and that tier’s stage, copied from the model catalogue and checked against it by a test. Read the stage before the tier: most of these are not built yet, and a card that says otherwise is a bug.

§4 / EXPERIMENTS

The ladder is a result, not a plan.

Every stop above was placed by trying to break it: pushing a frontier model down onto hardware that should not hold it, and pushing a tiny one up until it is useful. These are the runs that decide where the lines actually fall, with the stage each is at and what has come out so far.

FROM THE TOP

Can 2.8 trillion parameters fit on one workstation?

Kimi-K3 is 2.8T total with 104B active per token. The run tests whether pruning, low-precision execution and conversion together can put a frontier-scale model on a single high-memory box - which, if it works, moves the right-hand end of this ladder several stops to the left.

Current gate · 16K saliency calibration

SHIPPED

Why did a 284B model decode at 2 tokens a second?

The DeepSeek-V4-Flash work started as a hardware-fit question and turned into a runtime one: expert precision mattered more than any flag, and the format was missing multi-token prediction entirely, so we built MTP into the converter. The result is the one artifact on this page you can download.

Field note · the whole build, including what failed

MEASURED

How many people does one card actually serve?

A stop on this ladder is only real if the box serves more than one person at a time, so throughput is measured in aggregate under load rather than single-stream. This is the one machine on this page we measure on rather than specify against - our own bench:

4× RTX PRO 4500 · gpt-oss-120b · users swept 1 → 8
Aggregate~160 tok/s→~310 tok/s
Per user~171 tok/s→more than halved

Nearly double the work out of the same hardware, and the reason the single-stream number quoted everywhere badly understates a box.

Published · the sweep and what it costs to serve

FROM THE BOTTOM

How small can a model get and still be worth asking?

The other direction. Wave Pico targets 250–300M on a Raspberry Pi with no accelerator and a response near 50 ms - small enough to sit where the network stops, large enough to answer rather than classify. The waypoint is trained; the retrain at full size is the next gate.

HOW WE PUBLISH

Measurements name the hardware, the artifact, the runtime and the settings, and negative results stay up: the 2 tok/s mystery above is on the site because it was wrong for four different reasons before it was right. Everything lands in Open Air Waves as it happens.
